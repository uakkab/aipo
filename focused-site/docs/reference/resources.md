# Framework Resources

External standards, templates, and references that support the playbook pillars—especially Governance, Foundation, and Execution. Start from the [Framework](/docs/playbook/framework) or the [Implementation Guide](/docs/implementation/guide), then use these sources for depth. For readiness scoring, use the [Foundation Readiness Check](/docs/reference/foundation-check).

## Quick Reference: Free vs Paid

### Fully Free (Public Domain)

- NIST AI RMF (all documents + playbook)
- NIST Cybersecurity Framework 2.0 (all guides + templates)
- GSA AI Governance Toolkit

### Partially Free (Core Toolkit Free)

- ITIL (102 checklists free, certification paid)
- PMBOK (templates free, guide $99)
- COBIT (toolkit free, guides paid)
- CMMI (self-assessment free, certification paid)

**How to Use These Resources:** Start with NIST AI RMF (fully free) to establish governance fundamentals. Then layer in ITIL (service management), PMBOK (project delivery), COBIT (IT controls), and CMMI (process maturity) as your organization matures.
